Locally hosted interface fonts from the Google Fonts repository:

- Montserrat variable (100–900): https://github.com/google/fonts/tree/main/ofl/montserrat
- Kaushan Script Regular (400): https://github.com/google/fonts/tree/main/ofl/kaushanscript

Both fonts are distributed under the SIL Open Font License; the corresponding license files are included here. Montserrat supplies the main interface and bold heading weights. Kaushan Script is used only for the company name in the sidebar and navbar. These files are served by the app without external font requests.
